Polaris downloads the Qwen3-4B model (GGUF, Q4_0) on demand for the local
("On this server" / "On this device") Canopus assistant backend. The model runs
fully offline on the user's own hardware; it is not bundled with Polaris and is
fetched into the writable data directory when the user enables the local backend.
