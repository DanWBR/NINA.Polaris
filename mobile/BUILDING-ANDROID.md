# Building the Polaris Android APK

The mobile app is a **Capacitor** project (web UI + a Gradle Android
host). It is **not** a Visual Studio / .NET project, so the APK is built
with **Android Studio** or the **Gradle CLI** -- not the C# Visual
Studio. iOS (`.ipa`) needs macOS + Xcode and is covered separately.

Everything here happens inside `mobile/`. Nothing touches the rest of
the repo (`mobile/` is outside `NINA.sln`).

---

## 1. Install the toolchain (once)

- **Android Studio** (https://developer.android.com/studio). On first
  run it installs an SDK and a bundled JDK (JBR).
- In **Tools -> SDK Manager**, make sure these are checked:
  - Android SDK Platform **34**
  - Android SDK **Build-Tools**
  - Android SDK **Platform-Tools** (gives you `adb`)
- **Node** is already installed (Node 18+; we have 24).
- Capacitor 6 requires **JDK 17**. Android Studio's bundled JBR is 17,
  so you usually don't need a separate JDK.

> If a `gradlew`/`cap` command complains it can't find Java, point it at
> the Android Studio JDK:
> ```powershell
> $env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
> ```
> (adjust the path to your install).

## 2. One-time project setup

```powershell
cd C:\Users\danie\source\repos\DanWBR\nina-polaris\mobile
npm install                # app deps (Capacitor, plugins)
npm run plugin:build       # compiles the local polaris-onnx plugin  <-- REQUIRED first
npx cap add android        # generates the mobile/android Gradle project
npx cap sync android       # copies www/ + plugins into the Android project
```

`npm run plugin:build` must run **before** `cap sync`, otherwise the
native ONNX plugin won't be bundled.

Re-run `npx cap sync android` any time you change files under `www/` or
the plugin.

### App (launcher) icon

The launcher icon -- the round Polaris star you see in the phone's app
drawer -- is generated from the source images in `mobile/assets/`
(`icon-only.png`, `icon-foreground.png`, `icon-background.png`, all the
real Polaris brand at 1024px). Run this once after `cap add android`
(and again whenever the source images change):

```powershell
npm install            # first time: pulls @capacitor/assets
npm run icons          # writes mipmap-* + adaptive icons into android/
npx cap sync android
```

`npm run icons` regenerates the platform icons in the (git-ignored)
`android/` project, so re-run it after any fresh `cap add android`.

## 3. Debug APK (for testing on your own phone)

### Android Studio
1. `npx cap open android` (opens `mobile/android`).
2. **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
3. Click **locate** in the toast, or find it at:
   ```
   mobile/android/app/build/outputs/apk/debug/app-debug.apk
   ```

### Command line
```powershell
cd C:\Users\danie\source\repos\DanWBR\nina-polaris\mobile\android
.\gradlew.bat assembleDebug
# -> app\build\outputs\apk\debug\app-debug.apk
```

### Run straight on a device
- Enable **Developer options -> USB debugging** on the phone, connect it,
  and press the green **Run** ▶ in Android Studio (`npx cap run android`
  also works).
- Or copy `app-debug.apk` to the phone and open it (allow "install from
  unknown sources").

Debug APKs are signed with a throwaway debug key -- fine for your own
testing, not for sharing widely.

## 4. Signed release APK (to distribute, per the off-store plan)

### 4a. Create a keystore (once -- keep it safe + backed up!)
```powershell
# Uses keytool from the JDK (Android Studio's jbr\bin or your JDK\bin).
keytool -genkeypair -v `
  -keystore polaris-release.jks `
  -alias polaris `
  -keyalg RSA -keysize 2048 -validity 10000
```
You'll be asked for a keystore password, a key password, and a name.
**Back up `polaris-release.jks` and the passwords** -- losing them means
you can't ship updates that upgrade-in-place.

### 4b. Tell Gradle about it
Create `mobile/android/keystore.properties` (do NOT commit it):
```properties
storeFile=C:/full/path/to/polaris-release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=polaris
keyPassword=YOUR_KEY_PASSWORD
```

Add to `mobile/android/app/build.gradle` inside `android { ... }`:
```gradle
def keystorePropsFile = rootProject.file("keystore.properties")
def keystoreProps = new Properties()
if (keystorePropsFile.exists()) {
    keystoreProps.load(new FileInputStream(keystorePropsFile))
}

android {
    signingConfigs {
        release {
            if (keystorePropsFile.exists()) {
                storeFile file(keystoreProps['storeFile'])
                storePassword keystoreProps['storePassword']
                keyAlias keystoreProps['keyAlias']
                keyPassword keystoreProps['keyPassword']
            }
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
        }
    }
}
```
> `mobile/android/` is git-ignored (regenerated by `cap add`), so these
> edits live only on your machine. If you want them versioned, move the
> signing block into a small committed gradle snippet and `apply from:`
> it, or commit `android/` deliberately.

### 4c. Build it
- **Android Studio**: **Build -> Generate Signed Bundle / APK -> APK**,
  pick the keystore, choose **release**.
- **CLI**:
  ```powershell
  cd C:\Users\danie\source\repos\DanWBR\nina-polaris\mobile\android
  .\gradlew.bat assembleRelease
  # -> app\build\outputs\apk\release\app-release.apk
  ```

Share `app-release.apk`. Installers must allow "unknown sources".

## 5. Common snags

- **`SDK location not found`**: open the project once in Android Studio
  (it writes `local.properties`), or set `$env:ANDROID_HOME` to your SDK
  (usually `%LOCALAPPDATA%\Android\Sdk`).
- **`Failed to accept SDK licenses`**:
  ```powershell
  & "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" --licenses
  ```
- **Gradle uses the wrong Java**: in Android Studio,
  **Settings -> Build -> Build Tools -> Gradle -> Gradle JDK** = the
  bundled **jbr (17)**.
- **Plugin changes not showing**: re-run `npm run plugin:build` then
  `npx cap sync android`.
- **Self-signed Pi cert**: the app allows it in dev (`capacitor.config`
  `allowMixedContent`). For a hardened release, pin the fingerprint from
  `/api/system/server-cert` instead.

## 6. First smoke test

1. Install the APK, open the app -> the **connect** screen appears.
2. On the same Wi-Fi as the Pi, it should auto-list the host (mDNS), or
   type `polaris-app.local:5000`. Tap to load the live UI.
3. Open **Tools -> Aim helper**; "Polar align" works offline with just
   your latitude (no telescope needed) -- a good first validation.
