StarNet (v1) — star-removal model used by N.I.N.A. Polaris
===========================================================

Source project : StarNet by Nikita Misiura (nekitmm)
                 https://github.com/nekitmm/starnet
Polaris fork   : https://github.com/DanWBR/starnet
Author         : Copyright (c) Nikita Misiura
                 http://www.astrobin.com/users/nekitmm/

The "model.onnx" in this directory is converted (TensorFlow 1 checkpoint
-> ONNX) from the StarNet v1 pre-trained weights, using
scripts/convert-starnet-onnx.ps1 in this repository. It is the SAME neural
network, only re-serialized; no retraining or modification of the weights
was performed.
